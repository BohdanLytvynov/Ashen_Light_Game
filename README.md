# Ashen Light VR

> **Ashen Light** is an immersive, physics-driven Dark Fantasy VR action game built for Meta Quest and PCVR. 

Step into a decaying world shrouded in ash, where light is a luxury and survival is hard-fought. Experience visceral melee combat with authentic weapon weight, reactive physics, and full spatial control.

---

## ✨ Key Features

* **Physics-Based Combat System**  
  Every weapon carries weight and momentum. Block, parry, and strike with precise collision response and realistic feedback.
* **Immersive VR Locomotion**  
  Custom locomotion mechanics engineered for precise physical movement, smooth tracking, and minimal motion discomfort.
* **Atmospheric Dark Fantasy World**  
  Explore ruined citadels, ash-covered wastelands, and claustrophobic dungeons where danger lurks around every corner.
* **Interactive Environment**  
  Leverage environmental physics, cover, and destructible assets to gain the upper hand against relentless foes.

---

## 🛠 Tech Stack & Requirements

* **Engine:** Unreal Engine
* **Target Platforms:** Meta Quest 3 / PCVR
* **Language:** C++ / Blueprints
* **Input:** VR Motion Controllers (6DoF)

---

## 🚀 Getting Started

### Prerequisites
* Unreal Engine (4.27 or 5.x)
